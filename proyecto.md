# Análisis de hábitos académicos y rendimientos de estudiantes universitarios 

Este proyecto busca analizar algunos hábitos de los estudiantes universitarios para ver si existe alguna relación entre estos y su rendimiento académico.  

Decidimos por este proyecto considerando el desempeño de un estudiante no depende enteramente de sus hábitos de estudio, sino otras cosas como su asistencia a clase, cuanto duerme, la cantidad de créditos inscritos, o su tiempo dedicado al estudio.  

Como parte de este proyecto del taller, decidimos partir de una pregunta de interés y de un conjunto de datos que permita analizarla. En este caso, se utilizarían datos relacionados con los hábitos académicos de los estudiantes, para organizarlos, analizarlos y encontrar posibles patrones o relaciones entre las diferentes variables. 

Por ejemplo, se podría mirar si los estudiantes que estudian más horas tienen mejores promedios, si asistir más a clase se relaciona con mejores resultados o si una carga académica más alta puede afectar el desempeño.
